会员 · 独立教程

呼风唤雨

画质增强带来云层、水面与动态天气；配合语音口令可即时「刮风 / 下雨 / 下雪」。依赖画质增强，需先按下面步骤启用。

模块一：画质增强

功能：云层、水面光影、自然天气循环等画面增强。登录后从客户端启动游戏即可自动生效，无需额外开关。

  • 进局后画面增强会自动加载
  • 局内按 Home 可打开画质菜单，自行微调特效

模块二：语音天气口令

功能：说话切换风 / 雨 / 雪；可顺带播放天气氛围音乐（若已配置）。

  1. 先确保画质增强已生效（见上）
  2. 开启语音：Ctrl+Shift+F8（Edge 语音助手）
  3. 说口令，例如「风来」「下雨」「暴雪」
  4. 停止外置音乐：说「停止音乐」或按 Ctrl+Shift+F7

雨、雪大约持续两分钟后回到自然天气；「风来」会一直保持到说「风停」。任意地图都可强制下雨或下雪。

口令 效果 说明
风来 / 刮风 / 起风 / 大风 / 狂风… 起风 持续到「风停」
雨来 / 下雨 / 来点雨… 下雨 约两分钟
暴雨 / 下暴雨 / 大雨倾盆 暴雨 约两分钟
雪来 / 下雪 / 来点雪… 下雪 约两分钟
大雪 / 暴雪 / 下大雪 大雪 约两分钟
风停 / 雨停 / 雪停 停对应天气 回到自然天气
恢复自动 / 晴天 / 放晴 / 雨过天晴… 取消语音天气 完全恢复自动循环

模块三：天气氛围音乐

说「风来」「雨来」等时可播放对应氛围曲（可选配置）。播放时会暂时压低局内音乐，播完自动恢复。

  • 说「雨停 / 恢复自动」会停掉氛围曲并恢复局内 BGM
  • 也可随时按 Ctrl+Shift+F7，或说「停止音乐 / 静音」

扩展 · 独立教程

弹幕红警 · 怎么接入 / 怎么用

把抖音直播间接进客户端：观众送礼、发关键词弹幕、点赞可驱动红警刷兵与特效。 需先开通 主播权限（扩展，不在普通会员内）。

接入前准备

  1. 登录客户端，开通主播权限
  2. 准备抖音直播间，记下房间号（直播页 live.douyin.com/数字 里那串数字）
  3. 建议先进入一局红警对局（刷兵需要游戏在跑）

怎么接入直播间

  1. 对局中按 Enter 打开命令行
  2. 输入 /startliveroom 房间号（也可贴完整直播链接）后回车
  3. 若弹出浏览器：按提示扫码 / 手机号登录抖音（首次或登录失效时需要）
  4. 成功后提示已接入；可出现在线人数 / 点赞叠层
  5. 下播或换房：输入 /stopliveroom（同时只能监一个房间）
示例：/startliveroom 19309731874 · 命令帮助分组名「弹幕红警」；也可用 -help 查看。

礼物 / 弹幕会触发什么

送礼

  • 按礼物名映射刷敌军或我方援军
  • 部分礼物触发特殊效果（如核弹、铁幕、送钱、随机坦克等）
  • 单位可带观众昵称 / 祝福名牌

弹幕关键词

  • 默认需整句匹配（如发 1～9）
  • 同用户同词约 5 秒冷却，防刷屏
  • 命中后刷对应敌 / 我单位

点赞

点赞总数按阶梯触发刷兵（阶梯可配）。

其它互动

  • 特殊昵称进场音效
  • 弹幕自动回复（可配）
  • 仿 Dota 击杀 / 连杀播报
